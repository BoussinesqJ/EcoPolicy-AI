# 申报材料自动生成指南

## 定位

当用户说"帮我写申报材料""生成申报草稿""出一份申报指南"时，AI 参考本指南，结合政策原文和企业画像，自动生成标准化申报材料。

---

## 通用工作流

```
Step 1: 读取政策原文 → 提取申报要求（资格条件、材料清单、评审标准）
Step 2: 读取企业画像 → 填充具体数据（资质、财务、技术、团队）
Step 3: 选择模板类型 → 按政策类型匹配对应模板
Step 4: 逐项填充 → 标注 [待核实] 的部分需企业确认
Step 5: 质量检查 → 数据一致性、格式规范、逻辑自洽
Step 6: 输出 .md 文件 → 保存到企业工作目录
```

---

## 按政策类型分类的模板

### 类型 A：专项资金申报（拨改投/补贴/奖补）

**适用场景**：政府专项资金、财政补贴、产业发展基金

**标准章节**：

1. **项目基本信息**：项目名称、承担单位、推荐单位、所属领域、总投资、建设年限
2. **企业概况**：基本信息表（与营业执照一致）、主营业务、荣誉资质
3. **核心竞争力说明**：300-500 字，结构为"知识产权体系 + 核心技术能力 + 产业化能力"
4. **建设内容**：按模块展开（模块一/二/三），每个模块含投资金额、建设内容、设备购置、量化指标
5. **投资效益预估**：年新增营收/利润/税收、新增就业、投资回收期
6. **附件材料清单**：营业执照、可研报告、审批手续、审计报告、知识产权证明

**核心竞争力段落模板**：

> 公司核心竞争力体现在 [N] 个方面：
>
> **一、自主知识产权体系**。拥有 [X] 项发明专利、[X] 项实用新型专利，[X] 项省级科技成果登记，制定了 [X] 项行业/地方标准。
>
> **二、核心技术能力**。[描述技术优势]。[X] 年研发投入占营收 [X]%，高于行业平均水平。
>
> **三、产业化能力**。[描述生产/服务规模]。[量化数据：覆盖区域、客户数、年营收等]。

**建设内容段落模板**：

> 本项目围绕 [核心方向]，建设 [N] 个功能模块：
>
> **模块一：[名称]（投资约 [X] 万元）**。[建设内容]，购置 [设备]，实现 [量化指标]。
>
> **模块二：[名称]（投资约 [X] 万元）**。[建设内容]，购置 [设备]，实现 [量化指标]。
>
> **预期回报**：项目建成后预计 [量化收益]。

---

### 类型 B：资质认定申报（高企/专精特新/实验室）

**适用场景**：高新技术企业认定、专精特新、重点实验室、工程技术中心

**标准章节**：

1. **企业基本情况**：注册信息、员工结构、股权结构
2. **知识产权清单**：专利/软著/标准逐项列出
3. **科技成果转化**：近 3 年成果转化数量、转化方式、经济效益
4. **研发组织管理**：研发机构设置、研发人员占比、研发制度
5. **成长性指标**：近 3 年营收增长率、净资产增长率
6. **附件材料**：审计报告、知识产权证书、成果转化证明、研发费用辅助账

---

### 类型 C：项目审批/核准申报

**适用场景**：政府投资项目审批、企业投资项目备案、重大项目核准

**标准章节**：

1. **项目概况**：名称、建设地点、建设性质（新建/扩建/技改）
2. **建设必要性**：政策依据、市场需求、企业战略
3. **建设规模与内容**：产能/面积/设备/技术路线
4. **投资估算与资金来源**：总投资、自筹资金、银行贷款、政府补贴
5. **经济与社会效益**：财务内部收益率、投资回收期、就业带动
6. **审批文件**：立项文号、环评文号、规划许可证、土地审批

---

### 类型 D：投融资方案申报

**适用场景**：政府引导基金、产业基金、股权融资配套政策

**标准章节**：

1. **企业估值与融资需求**：当前估值、拟融资金额、出让比例
2. **资金用途**：研发/产能/市场/团队各占比
3. **退出路径**：IPO/并购/回购/股权转让的时间表和条件
4. **财务预测**：未来 3-5 年营收/利润/现金流预测
5. **风控措施**：核心风险识别与对冲策略

## 输出格式规范

所有生成的申报材料遵循以下规范：

| 规范项 | 标准 |
|:--|:--|
| **格式** | Markdown 商务简报风格 |
| **元数据** | YAML frontmatter（title/date/author/type/enterprise/policy） |
| **数据来源** | 企业画像中的数据直接填入，无法确定的标注 [待核实] |
| **数字格式** | 千分位分隔（如 3,000 万元）、百分比保留整数 |
| **段落长度** | 核心段落 300-500 字，避免过长 |
| **表格** | 统一对齐（`:--` / `:--:` / `--:`） |
| **审批提醒** | 用 `> [!WARNING]` 标注关键注意事项 |

## 质量检查清单

生成后自动检查：

- [ ] 所有 [待核实] 标注不超过 10 处
- [ ] 核心竞争力段落包含具体数据（不是空洞描述）
- [ ] 建设内容与投资规模匹配
- [ ] 附件材料清单完整（对照政策要求）
- [ ] 无敏感信息泄露（企业名/人名/联系方式脱敏）
- [ ] 格式符合 output_standards.md 规范
