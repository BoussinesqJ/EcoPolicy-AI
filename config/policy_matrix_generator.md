# PolicyMatch Matrix Generator

# 本文档定义了"经济政策智能分析系统"的核心分析引擎。

---

## 一、核心原理

任何经济政策对企业的影响力，都可以拆解为四个维度：

| 维度 | 英文代号 | 核心问题 |
|:--|:--|:--|
| **技术端** | Tech | 这项政策对企业核心技术能力的影响是什么？ |
| **生产端** | Prod | 这项政策对企业生产运营条件的影响是什么？ |
| **市场端** | Mkt | 这项政策对企业的市场准入、渠道和补贴的影响是什么？ |
| **资本端** | Cap | 这项政策对企业的融资、合规和资本路径的影响是什么？ |

四维评分规则：每项 1-5 分，总分 20 分。

| 总分 | 匹配等级 | 行动建议 |
|:--:|:--|:--|
| 17-20 | 5/5 首选推荐 | 立即启动申报/利用程序 |
| 13-16 | 4/5 强烈推荐 | 评估后优先推进 |
| 9-12 | 3/5 推荐 | 条件具备时可参与 |
| 5-8 | 2/5 一般 | 观望，等待配套细则 |
| 1-4 | 1/5 不适用 | 不建议投入精力 |

## 二、行业分析框架库

### 2.1 种业 / 农业

| 维度 | 分析要素 |
|:--|:--|
| **Tech** | 生物育种技术路线（基因编辑/分子标记/转基因）、种质资源创新、品种审定标准变化、EDV 制度 |
| **Prod** | 制种基地土地政策、水利配套、农业保险、南繁基地政策、制种机械化补贴 |
| **Mkt** | 良种补贴标准、品种推广区域政策、惠农政策要求、种业知识产权保护 |

### 2.7 通用模板（其他行业适用）

| 维度 | 分析要素 |
|:--|:--|
| **Tech** | 政策是否直接支持企业的核心技术方向？是否有研发补贴/平台建设支持？ |

| **Mkt** | 政策是否打开了新的市场准入机会或提供了补贴/采购倾斜？ |
| **Cap** | 政策是否拓宽了融资渠道或影响了合规/上市路径？ |

## 三、动态框架生成规则

当企业所在行业不在上述预置列表中时，AI 按以下规则自动生成四维框架：

### Step 1：提取行业关键词

从企业画像的 `industry_keywords` 中提取 3-5 个核心关键词。

### Step 2：匹配最近似行业

将关键词与上述 6 个行业模板对比，选择重叠度最高的作为基线模板。

### Step 3：定制化修正

根据企业画像中的 `sub_sector`、`main_products`、`research_platforms` 等字段，对基线模板中的分析要素进行增删。

### Step 4：生成专属矩阵

输出格式：

```
{企业简称} PolicyMatch Matrix — {行业} 行业

| 维度 | 分析要素 | 政策相关条款 | 评分 |
|:--|:--|:--|:--:|
| Tech | ... | ... | X/5 |
| Prod | ... | ... | X/5 |
| Mkt  | ... | ... | X/5 |
| Cap  | ... | ... | X/5 |
| **合计** | | | **XX/20** |
```

## 四、匹配度评分细则

### 4.1 硬性条件匹配（门槛判定）

| 条件类型 | 匹配 | 不匹配 |
|:--|:--|:--|
| 注册地/纳税地 | 继续评估 | 直接淘汰 |
| 注册资本门槛 | 继续评估 | 差距 < 20% 可争取，> 20% 淘汰 |
| 行业/产业方向 | 继续评估 | 若为"鼓励类"加分，"限制类"淘汰 |
| 资质要求（高企/专精特新等） | 加分项 | 可补办的标记为待办 |
| 信用/合规要求 | 必须满足 | 一票否决 |

### 4.2 定量评估（打分制）

每项 1-5 分，评分标准：

| 分数 | 含义 | 判定标准 |
|:--:|:--|:--|
| 5 | 完美匹配 | 政策直接点名支持企业所在细分领域 |
| 4 | 高度匹配 | 政策覆盖企业所在大类，有明确支持条款 |
| 3 | 部分匹配 | 政策间接涉及，需要创造条件才能享受 |
| 2 | 弱匹配 | 仅在原则性条款中提及，无具体支持措施 |
| 1 | 不匹配 | 与企业业务无实质关联 |

### 4.3 定性评估（机会/风险标签）

每个维度输出两组标签：

- **机会标签**：政策给企业带来的直接利好
- **风险标签**：政策可能给企业带来的合规压力或竞争威胁

## 五、使用示例

### 示例：某种业科技企业 vs "拨改投"政策

```
PolicyMatch Matrix — 种业/制造业

| 维度 | 分析要素 | 政策相关条款 | 评分 |
|:--|:--|:--|:--:|
| Tech | 生物育种技术创新 | "农业微生物与生物育种"列入千亿级产业集群 | 5/5 |
| Prod | 制种基地建设 | "设备购置"+"流程改造"覆盖分子育种实验室 | 4/5 |
| Mkt  | 品种推广+惠农政策 | "现代农产品加工"延伸产业链 | 4/5 |
| Cap  | 区域股权交易中心融资路径 | "拨改投"本身即是资本端创新（政府股权投资） | 5/5 |
| **合计** | | | **18/20** |

匹配等级：5/5 首选推荐
```

## 六、注意事项

1. **框架只是起点**：四维矩阵是通用分析框架，具体到每个政策还需结合政策原文深入分析
2. **评分要诚实**：如果政策对企业影响有限，应如实打低分，而非刻意拔高
3. **关注执行细则**：很多政策的"魔鬼在细节"，框架分析后还需追踪配套细则
4. **时效性**：政策有申报窗口期，评分之外还要评估紧迫度（P0/P1/P2）
