## 四、政策监控策略

### 4.1 监控频率

| 优先级 | 频率 | 适用源 |
|:--|:--|:--|
| 高频 | 每日 | 企业注册地省级厅局网站、工信部、农业农村部 |
| 中频 | 每周 | 国务院、发改委、财政部、科技部 |
| 低频 | 每月 | 其他省份政策（跨区域机遇监控） |

### 4.2 关键词监控

| 类别 | 监控关键词 |
|:--|:--|
| 通用 | 专项资金、补贴、奖励、扶持、申报、认定、试点、示范 |
| 种业 | 种业振兴、生物育种、品种审定、南繁、种质资源 |
| 制造业 | 技改、智能制造、专精特新、小巨人、首台套 |
| 数字经济 | 数据要素、算力、人工智能、大模型、数字经济 |
| 新能源 | 碳达峰、碳中和、新能源、储能、氢能、碳交易 |
| 资本 | IPO、北交所、科创板、产业基金、股权投资 |

### 4.3 政策分类

每条监控到的政策按以下标签分类：

| 标签 | 含义 | 后续动作 |
|:--|:--|:--|
| [资金补贴] | 有明确的资金支持 | 优先分析，对标企业画像 |
| [税收优惠] | 减免税/加计扣除 | 排查所有企业适用性 |
| [认定资质] | 需要申请认定 | 评估企业是否满足条件 |
| [产业规划] | 中长期规划方向 | 影响企业战略决策 |
| [监管合规] | 新增合规要求 | 风险预警 |
| [准入许可] | 市场准入变化 | 机遇/风险双向评估 |
