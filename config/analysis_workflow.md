# ========================================================
# 六步标准分析工作流
# EcoPolicy Analysis Workflow
# ========================================================
# 本文档定义了从"政策录入"到"输出决策建议"的完整工作流。
# 每次分析新政策时，AI 助手将严格按此六步执行。
# ========================================================

---

## 工作流总览

```
Step 1: 政策录入         → 结构化政策摘要
Step 2: 画像匹配         → 硬性条件通过/淘汰 + 差距清单
Step 3: 多维拆解         → 四维矩阵评分（Tech/Prod/Mkt/Cap）
Step 4: 赛道设计         → 1-3条申报/利用路径 + 对比表
Step 5: 行动清单         → P0/P1/P2分级行动 + 材料清单
Step 6: 深度报告（按需） → 申报指南 / 退出方案 / 可研大纲
```

---

## Step 1: 政策录入

### 1.1 输入方式

| 方式 | 操作 | 适用场景 |
|:--|:--|:--|
| 网页链接 | 用户粘贴 URL，AI 自动抓取全文 | 官网政策公告 |
| PDF/文件 | 用户上传文件附件 | 申报指南、实施细则 |
| 文本 | 用户直接粘贴政策文本 | 截图转文字、内部文件 |
| 关键词搜索 | 用户描述政策主题，AI 主动搜索 | "找一下最近的种业补贴政策" |

### 1.2 结构化摘要

AI 提取以下字段并输出表格：

| 字段 | 说明 | 示例 |
|:--|:--|:--|
| 政策名称 | 完整标题 | 制造业领域财政专项资金"拨改投"改革试点 |
| 发文机关 | 发文单位 | 湖北省经济和信息化厅 |
| 发文日期 | 发布日期 | 2026-05-15 |
| 文号 | 如有 | |
| 政策类型 | 分类 | 资金补贴 / 税收优惠 / 准入许可 / 产业规划 / 其他 |
| 适用区域 | 地理范围 | 湖北省 / 全国 / 特定园区 |
| 申报截止 | 截止日期 | 待确认 |
| 核心机制 | 100字内概括 | 财政资金以增资扩股方式注入企业... |
| 原文链接 | 可溯源 URL | |

---

## Step 2: 画像匹配

### 2.1 硬性条件逐条比对

将政策中的"申报条件/适用范围"逐条提取，与企业画像逐项对照：

| 比对项 | 政策要求 | 企业现状 | 判定 |
|:--|:--|:--|:--|
| 注册地 | 湖北省内 | 湖北省某市 | [通过] |
| 注册资本 | >= 2000万 | XXXX 万元 | [通过] |
| 行业方向 | 生物育种 | 杂交玉米育种 | [通过] |
| 高企资质 | 需高新技术企业 | 国家高企 | [通过] |
| 环评手续 | 需办理 | 部分待补 | [差距] |

### 2.2 匹配判定

| 判定结果 | 含义 | 后续动作 |
|:--|:--|:--|
| 全部通过 | 满足所有硬性条件 | 进入 Step 3 |
| 部分差距 | 可在窗口期内补齐 | 标记待办项，进入 Step 3 |
| 关键缺失 | 存在不可弥补的硬伤 | 终止分析，输出"不建议申报"结论 |

---

## Step 3: 多维拆解

### 3.1 运行 PolicyMatch Matrix

根据企业所在行业，从 `policy_matrix_generator.md` 中选取对应框架，逐维分析：

| 维度 | 分析内容 | 输出 |
|:--|:--|:--|
| Tech | 政策对技术创新的直接支持力度 | 评分 + 机会标签 + 风险标签 |
| Prod | 政策对生产运营条件的改善程度 | 评分 + 机会标签 + 风险标签 |
| Mkt | 政策对市场准入和补贴的贡献 | 评分 + 机会标签 + 风险标签 |
| Cap | 政策对融资和资本路径的影响 | 评分 + 机会标签 + 风险标签 |

### 3.2 输出格式

```
| 维度 | 评分 | 机会 | 风险 |
|:--|:--:|:--|:--|
| Tech | 5/5 | 生物育种直接命中千亿级产业集群 | 技术验收标准待明确 |
| Prod | 4/5 | 设备购置补贴覆盖分子育种实验室 | 制种基地不在补贴范围内 |
| Mkt  | 4/5 | 鲜食玉米深加工符合"农产品加工"方向 | 区域市场有竞争 |
| Cap  | 5/5 | "拨改投"是资本端创新（政府股权投资） | 5年退出压力 |
| 总计 | 18/20 | | |
```

---

## Step 4: 赛道设计

### 4.1 逻辑

基于 Step 3 的矩阵评分，为企业推荐 1-3 条可申报/可利用的路径：

| 优先级 | 推荐级别 | 条件 |
|:--|:--|:--|
| [1st] | 5/5 首选推荐 | 四维总分 >= 17，硬性条件全部满足 |
| [2nd] | 4/5 强烈推荐 | 四维总分 13-16，部分差距可补齐 |
| [3rd] | 3/5 推荐 | 四维总分 9-12，需要创造条件 |

### 4.2 每条赛道输出

| 输出项 | 内容 |
|:--|:--|
| 赛道名称 | 简洁描述（如"生物育种技术创新平台"） |
| 核心逻辑 | 为什么这条赛道最适合（100字内） |
| 投资规模 | 预估总投资金额 |
| 优势 | 企业在此赛道的核心竞争力 |
| 风险 | 主要不确定性 |
| 匹配度 | X/5 分 推荐级别 |

---

## Step 5: 行动清单

### 5.1 分级标准

| 等级 | 时限 | 含义 | 示例 |
|:--|:--|:--|:--|
| P0 | 本周内 | 不立即行动则错过窗口 | 联系主管部门确认推荐名额 |
| P1 | 2-4周内 | 重要但有缓冲期 | 编写可研报告、整理审计报告 |
| P2 | 持续 | 长期关注项 | 跟踪政策细则、了解同行动态 |

### 5.2 输出格式

```
| 优先级 | 行动项 | 负责方向 | 时限 | 依赖 |
|:--|:--|:--|:--|:--|
| P0 | 联系主管部门确认推荐名额 | 总经办 | 本周 | 无 |
| P0 | 确定主攻赛道，报决策层 | 战略 | 本周 | 无 |
| P1 | 启动可研报告编制 | 技术+财务 | 2周 | P0-赛道确定 |
| P1 | 准备近3年审计报告 | 财务 | 2周 | 无 |
| P2 | 研究受托机构投资偏好 | 战略 | 持续 | 无 |
```

### 5.3 材料清单

同步输出所需提交材料的准备状态：

```
| 序号 | 材料 | 状态 | 负责 |
|:--|:--|:--|:--|
| 1 | 营业执照 | 已有 | 行政 |
| 2 | 可行性研究报告 | 待编写 | 第三方 |
| 3 | 审计报告 | 待整理 | 财务 |
```

## Step 6: 深度报告（按需）

当用户明确要求时，基于前五步的分析结果，生成以下专项报告之一：

### 6.1 申报书填报指南

适用场景：政策需要填写正式申报书

输出内容：
- 逐表逐项填写指导（对照企业画像数据）
- 核心竞争力标准化陈述段落
- 项目名称/投资规模/建设内容建议

### 6.2 退出路径方案

适用场景：政策涉及政府股权投资或需设计退出机制

输出内容：
- 政策退出约束条款解读
- 企业退出能力评估
- 多条退出路径设计（含时间轴、财务测算、优劣对比）
- 风险矩阵与对冲策略
- 协议谈判关键条款建议

### 6.3 可研报告大纲

适用场景：政策要求提交可行性研究报告

输出内容：
- 标准章节结构（项目背景、技术方案、市场分析、财务测算、风险评估）
- 针对企业的预填内容框架
- 关键数据需求清单（指导企业准备材料）

### 6.4 政策对比分析

适用场景：企业面临多个可选政策，需做取舍

输出内容：
- 多政策横向对比表（资金规模、申报难度、紧迫度、战略价值）
- 推荐排序与理由

---

## 工作流的执行原则

1. **严格按序执行**：Step 1-5 依次进行，不跳步
2. **每步都输出**：即使某步结论是"不适用"，也要明确告知用户
3. **数据驱动**：所有评分和判定必须基于政策文本事实和企业画像数据
4. **行动导向**：最终输出必须是"用户看完就知道该做什么"
5. **可溯源**：引用政策原文时标注条款位置
6. **保密意识**：企业财务数据等敏感信息不外传
