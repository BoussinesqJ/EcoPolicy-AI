# 拨改投退出路径方案设计

> **核心结论**：首选 IPO 退出 -- 企业已挂牌区域股权市场，转板路径最短；备选战略投资者接盘 + 企业回购兜底。

| 投资期限 | <= 5 年（投资 + 退出） | 倒推时间表，2026 年进入，2031 年前退出 |

| 定价原则 | 原则不低于原始出资额 | 可约定让利条款 |
| 投后管理 | 需定期报告经营数据 | 信息披露制度化 |

### 路径 A：IPO（5/5 分 首选推荐）

- [行业] 赛道正受政策热捧，审核友好

### 路径 B：战略投资者接盘（4/5 分 强烈推荐）

与 IPO 并行推进，互为保险。可引入产业资源，实现 1+1>2。

**潜在接盘方画像：**
- 大型 [行业] 集团（产业协同）
- 产业基金（财务投资）
- 地方国资平台（政策配合）

### 路径 C：企业自有资金回购（3/5 分 推荐）

作为终极安全网。审批最简单，控制权最安全。

**资金来源：**
- 经营利润积累
- 银行授信贷款
- 股东借款

### 路径 D：组合方案

上述路径的灵活组合。建议以 IPO 为主路径，同时维护 1-2 个备选接盘方。

## 七、核心建议

### 应写入投资协议的 5 条退出条款

1. **IPO 触发退出条款**：企业 IPO 获批后，政府方有权在锁定期满后优先转让
2. **估值保护条款**：退出价格不低于原始出资额 * (1 + LPR * 年限)
3. **回购触发条款**：5 年期满未实现 IPO 或股权转让，企业有权按约定价格回购
4. **信息权条款**：政府方享有年度审计报告查阅权，但负有保密义务
5. **反稀释条款**：后续融资中，政府方持股比例不被不合理稀释
